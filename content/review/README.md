# Review

Este diretório existe para preservar a estrutura editorial no Git.

- Recebe artigos aguardando revisão e aprovação humana.
- Nada neste diretório é publicado automaticamente.
- A revisão deve cobrir conteúdo, fatos, SEO, acessibilidade, links e imagem.
- Somente conteúdo aprovado deve ser movido manualmente para `content/posts/`.

Conteúdo público deve permanecer em inglês. Não colocar segredos ou dados sensíveis neste diretório.
