# Cover Generation Rules

Before generating a new article cover:

1. Read `VISUAL_STYLE_GUIDE.md`.
2. Read `content/visual/cover-manifest.yml`.
3. Inspect several gold-standard reference covers from `src/assets`.
4. Translate the article's core public-finance concept into a unique civic visual metaphor.
5. Preserve the established navy / gold / ivory editorial family without cloning an earlier composition.
6. Generate a text-free final master in a high-resolution landscape composition suitable for the Insights card and article hero.
7. Place the approved final asset in `src/assets`.
8. Add the asset to the manifest only after human visual approval.
9. Run content validation before publication.

A generated image is not publication-ready merely because it exists. Visual approval is a required editorial gate.

## Pairing

EN/PT-BR translations use the same master image with localized alt text.

## File naming

Use:

`article-<concept-slug>-hero.jpg`

or another approved raster extension.

SVG may be used for diagrams inside article content, but not as a final editorial cover under this policy.
